# 🌤️ Interactive Mood Journal with Weather Integration

A responsive web application that lets users log their mood, notes, and view real-time weather – perfect for reflecting and tracking emotional wellness. Designed as a frontend intern/fresher assessment project.


---

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript + Tailwind CSS
- **UI Framework**: shadcn-ui
- **Bundler**: Vite
- **Data Storage**: LocalStorage
- **API**: [OpenWeatherMap API](https://openweathermap.org/api)

---

## 🚀 Getting Started

Clone and run the project locally:

```bash
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
